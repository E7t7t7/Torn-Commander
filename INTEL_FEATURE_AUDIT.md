# Torn Intel comparison — 2026-10-15

Audit sources: https://torn-intel.com/ ; signed-in Activity, Company, Abroad and Stock Market pages; https://torn-intel.com/developers ; https://torn-intel.com/privacy .

This is an implementation inventory, not a claim of full parity. No site source code, branding images, private database, model or user API key is bundled. Native tools use the user's existing Commander credential through the official Torn API. The optional website workspace uses its normal browser login and subscription permissions.

| Feature group | Commander coverage | Remaining work / dependency |
|---|---|---|
| Foreign stock, filters, departure and day plans | Existing native travel tools | Comparable traffic/mugging history, per-item landing overrides, pinned sell prices, history reports and forecast calibration need more work; no access to Torn Intel forecast model |
| Company costs, history, staff optimiser, explanations | Existing native company tools | Historical backfill, pricing experiments, charts, director share, sharing, exports |
| Sunday stars | Native listing comparison | Calibrated probabilities need multi-Sunday training and holdout data plus hidden-unlock treatment |
| Stock market | New native portfolio, sampled charts/range, net P/L, first block cost, custom payout scenario and price targets | Full exchange historical backfill, benefit tier projections, automatic item valuation and remote alerts |
| Faction members and leadership | Existing native roster, role-aware guidance, crimes, chains, wars, upgrades | Extended member personal-stat history and detailed reports |
| Activity charts and heatmaps | New opt-in 5-minute local observations, member percentages, hourly/week-day heatmap | Not continuous uptime or imported site history; only active profile while app runs |
| Player/faction/alliance profiles | Existing own-faction scan | Arbitrary faction comparison, player histories and shared alliance backend |
| Personal-stat library, gym history | Existing personal progression summary | Per-member history access and permission-aware time series |
| Chain reports and war reporting | Current chain/war snapshots | Per-hit report import, milestones, contribution analysis and payout calculations |

The site's Pro-only buttons do not grant access on this account. No payments, war actions, messages, purchases or faction settings were submitted during inspection. Login and site API key handling were explicitly approved by the user.
