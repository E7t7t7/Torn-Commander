TORN COMMANDER v0.6.11 – THEME AND UPDATER TEST

1. Start a working installation of Build v0.6.10. Settings > Update Commander > Check GitHub for Update.
2. Confirm update to v0.6.11. The app should close, stage the new build, and reopen showing Build v0.6.11.
3. In Settings > Commander color theme, select Emerald, Obsidian, Amethyst, Ember, then Midnight Blue.
4. Confirm the dashboard, navigation, card backgrounds, input borders and buttons change immediately (Torn game pages do NOT change).
5. Select your preferred theme, close Commander, reopen it: the selection must remain.
6. Switch account profiles, then return to Settings: theme stays the same across profiles on this Windows installation.
7. Inspect %LOCALAPPDATA%\TornCommander\update-last.log after installation if update fails; send the error lines.

These checks do not modify stored Torn sessions or credentials.
