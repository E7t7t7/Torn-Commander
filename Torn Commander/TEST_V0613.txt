Torn Commander v0.6.16 — Shortcut and versioned install repairs

1. Extract the v0.6.16 source ZIP into a freshly named Torn_Commander_v0.6.16 folder, or use the installed updater once.
2. Run REBUILD_AND_LAUNCH.bat and verify Build v0.6.16.
3. Close Commander and run CREATE_DESKTOP_SHORTCUT.bat. It must create a valid T-branded Windows shortcut without a parser error.
4. Verify the desktop shortcut points to the NEW v0.6.16 EXE, not a v0.6.14 or earlier folder.
5. Test Torn Commander.bat to confirm launching the active EXE.
6. Existing profiles, cookies, API keys and themes must still load from %LOCALAPPDATA%.
7. The version-folder feature affects updates STARTING FROM a v0.6.16 app. If an old updater was used to install v0.6.16, its parent folder may still have the older version name. A fresh v0.6.16 installation avoids that mismatch.
8. Next future v0.6.17+ update should create Torn_Commander_vX.Y.Z/Torn Commander as a version-named sibling, leave the old folder in place, and open the new EXE.
9. Check the updated desktop shortcut points at the new versioned folder.
10. If updating fails, send %LOCALAPPDATA%\TornCommander\update-last.log (not private data).

GitHub CI verifies PowerShell syntax, T .lnk creation and a simulated versioned update with locked old EXE directory.
