Torn Commander v0.6.17 — Version manager and rollback

1. Update from v0.6.16 to v0.6.17 through Settings > Check GitHub for Update.
2. The new executable must run inside Torn_Commander_v0.6.17/Torn Commander/dist.
3. The dark T desktop shortcut must point at the active v0.6.17 EXE automatically.
4. Older app folders should be retired automatically when Windows unlocks them; if Windows keeps a file open they are preserved for safe manual cleanup.
5. In Settings > In-app Updates, the saved version dropdown should offer v0.6.16 once the update has succeeded.
6. Confirm the restore prompt and switch to v0.6.16; the current v0.6.17 must be saved in the rollback library.
7. Verify login profiles and API credentials are unchanged under LOCALAPPDATA.
8. Rolling back intentionally removes later v0.6.17-only UI features until the next upgrade.
9. If rollback fails, do not repeatedly retry. Send update-last.log and update-build-last.log.
10. CI checks the versioned-folder install/restore using locked prior executables on a disposable Windows test fixture.
