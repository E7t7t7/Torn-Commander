Torn Commander v0.6.14 — Locked directory updater regression

1. If already running v0.6.10 or newer, click Settings > Check GitHub for Update.
2. A new version should build in staging and install under a dist-v0.6.14-xxxxxxxx directory.
3. No attempts to rename or delete the old dist should be logged.
4. Check the active VERSION badge shows 0.6.14 and your accounts/sessions persist.
5. Close and reopen using the dark T Desktop shortcut: it should target the new version.
6. Torn Commander.bat from the source root should also launch the active version.
7. A taskbar shortcut directly pinned to the old EXE may need to be re-pinned.
8. If needed, the old dist remains intact for recovery.
9. Windows CI uses a separate lock-holding process to verify that updates work while the old dist is in use.
