# Burglary / hustling sessions
In Crime Coach choose thresholds, open the selected crime and a property/game if needed, Scan controls, then Run session. Keep that game tab open.
Burglary scouts ordinary districts, cases until your confidence threshold and burglarizes. Confidence is not an exact success probability.
Hustling gathers, demos below your interest threshold and attempts winning above it for the selected visible game. High suspicion or unreadable values pause. No intentional losing, helpers, tool purchases or refills.
Ranking uses this account's last 50 matching observations after three samples. With insufficient history it uses readiness rules. Cash rewards exclude unpriced loot and other costs; they are not net profit.
Pause/Stop check a dispatched result and start no next action. Resume checks the same pending receipt. After a page change/restart, review Torn before clearing an interrupted action. Unknown controls pause. No live nerve spent during development; Edge fixtures verify protocol, not every Torn layout.
Mechanics: https://wiki.torn.com/wiki/Burglary and https://wiki.torn.com/wiki/Hustling. Receipt field reference reviewed from https://github.com/Mephiles/torntools_extension/blob/master/src/common/pages/crimes2-page.ts; no third-party source copied.
