# Gorilla Discord fallback
In Loss Desk expand **Fallback: Gorilla Mercenary Services**.
1. Open the Gorilla Discord contract and press Join Contract there yourself, using the Discord identity linked to the Torn account you want to sell from.
2. Copy only that message's complete Live Contract Progress card. Paste the text into Commander; optionally add its Copy Message Link.
3. Preview, check target and price, choose your personal remaining batch and confirm your join as the selected Torn account. Use current-energy estimate if useful.
4. Create the local batch, then press Start A in Loss Desk. Importing never starts an attack.
5. Use the normal loss-worker/medical controls and record actual received payments through the existing settlement controls. Open Discord and Leave Contract there if you cannot continue.

Shared verified/remaining totals cover all vendors and are not your reservation or personal delivery count. Copied text is not live provider verification. Other vendors can consume remaining work before you do; verify in Discord and use bounded batches. After 15 minutes stop the worker, copy current progress and re-import. Refreshing preserves completed deliveries and sets the new remaining batch.

If a vendor list is included, this account must appear active rather than removed. If omitted, the join is only your explicit manual confirmation. Each profile requires its own valid join; a second account does not inherit the first one's Discord membership/claim.

No documented Gorilla integration API was found during development. Automatic Join/Leave, discovery and mobile/home synchronization are unavailable in this version. No ordinary Discord user tokens or unsupported bot interaction endpoints are used. An owner-supported API or approved bot integration would be needed for fuller automation.
